# Antique MERA keys

Five separate RGBA PNG assets generated with the built-in image_gen tool. Transparent pixels and the openings within the ornaments are retained. Stable filenames correspond to the existing saved key IDs; changing the artwork does not reset progress.

Final prompt set:

Entire key upright, centered, fills 90% image height, no cropping. Elaborate rounded quatrefoil pierced bow, tiny gold finial, delicate curled flourishes at neck, turned slender cylindrical shaft, small squared antique key bit. Rich warm gold, restrained aged dark patina in crevices, polished edges, convincing sculpted 3D metal. Transparent background with true alpha including holes inside bow.
